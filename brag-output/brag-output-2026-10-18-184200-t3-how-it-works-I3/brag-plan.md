# Brag Plan: DriftLock — T3 how-it-works · I3 cinematic · landscape 1920x1080 · 20s

## What is this app?
DriftLock is "Dependabot, but for APIs."

## The angle
Trailer-scale explainer. Big numbers 01–04, sweeping transitions, RMS pulse on each step lock. Dramatic.

## Hook (first 2-3 seconds)
Black → big mono: "SCAN. CAPTURE. DIFF. FIX PR." One word at a time, holds.

## Key moments (the middle)
- 01 Scan — AST finds every vendor call site (big 01)
- 02 Capture — sandbox proxy records real shapes (big 02)
- 03 Diff — added / removed / type-changed, confidence 0–100 (big 03)
- 04 Fix PR — deterministic rename; PR via GitHub API (big 04, emerald)
- RMS pulse on each step lock; lock draw, tagline, driftlock.dev

## Outro / punchline
"DriftLock." Held tagline + URL. Mute-safe final 2s hold.
