TWO SURFACES

Outbound calls. Inbound
webhooks. One pipeline.

OUTBOUND · APIs you call

  • stripe.charges.create, stripe.refunds.create
  • POST /v1/charges — endpoint inferred
  • Fix edits request arguments

INBOUND · webhooks you receive

  • payment_intent.succeeded payload
  • data.amount → "number" flattened
  • Fix edits payload readers only

A drift in one surface never authorizes an edit to the other. Separate contracts, same PR model.
